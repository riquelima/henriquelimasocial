PASSO 02 / 04 AUTOMAÇÃO • MODEL CONTEXT PROTOCOL

Ative o Servidor de Automação MCP nos Ajustes

O grande diferencial desta versão é o suporte nativo ao Model Context Protocol (MCP). Isso transforma o editor em um servidor local com o qual agentes de IA podem conversar diretamente para posicionar clipes, aplicar transições, sincronizar trilhas de áudio e renderizar o projeto.

COMO HABILITAR O MCP:
  • 1 Abra o Instagram Edits e clique em Ajustes (ou pressione Cmd + ,).
  • 2 Na barra lateral esquerda, clique na aba Automação.
  • 3 Ative a chave MCP Ativado (Habilita o servidor de automação).
  • 4 O endereço local será http://127.0.0.1:19501/mcp. Clique no botão Copiar ao lado de Token de Acesso.
ATENÇÃO DE SEGURANÇA: Mantenha seu Token em sigilo! Ele concede controle de automação sobre sua biblioteca de projetos.
PASSO 03 / 04 TERMINAL • CLAUDE CODE CLI

Conecte o Edits ao Claude Code via Terminal

Com o servidor local ativo e seu token em mãos, basta registrar o Edits como um MCP server no seu Claude Code. Abra o Terminal do Mac e execute o comando abaixo:

TERMINAL DO MACOS • REGISTRO MCP BASH 
claude mcp add --transport http \
  --scope user edits \
  http://127.0.0.1:19501/mcp \
  --header "Authorization: Bearer SEU_TOKEN"
